Configuración inicial \u00b7 Supabase

Conecta tu base de datos

El CRM necesita una cuenta gratuita en Supabase para guardar prospectos, citas y usuarios en la nube. Sigue estos pasos una sola vez:

1

Crea tu proyecto en Supabase

Entra a supabase.com \u2192 New Project \u2192 elige nombre y contraseña. Es gratis para proyectos pequeños.

2

Ejecuta el SQL de configuración

En tu proyecto, ve a SQL Editor y pega el contenido del archivo supabase-setup.sql que se descargó junto con este CRM. Da clic en Run.

3

Copia tus credenciales

En tu proyecto: Settings \u2192 API. Necesitas el Project URL y la anon public key.
